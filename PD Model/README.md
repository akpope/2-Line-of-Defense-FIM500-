# 2-Line-of-Defense-FIM500

## Project 3: Probability of Default Model

This folder contains 4 files needed for validating/documenting this model;

model.py - Python script containing the mode

model.ipynb - Jupyter notebook with the training, testing, and building of the model

model_documentation.ipynb - Documentation notebook with all relevant information 

cs-test.csv.zip - Data meant to be used for validation

There are also two .png files for relevant graphs for the documentation notebook.
